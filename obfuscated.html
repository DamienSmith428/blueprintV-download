A free Windows desktop app for FiveM vehicle creators. Drop your resource folder in, and blueprintV extracts every UV shell from your .yft models, renders them as wire-frame overlay template PNGs at up to 4K, and automatically patches carcols.meta and carvariations.meta — all in seconds.

// How It Works

01

Download & Launch

Download blueprintV.exe and run it — no installation required. Requires Windows and .NET Framework 4.8, which is built into Windows 10 v1903+ and Windows 11.

02

Point it at your resource

Use the drag-and-drop interface or the folder browser to select your FiveM vehicle resource. blueprintV will locate all .yft model files automatically.

03

Generate your templates

blueprintV reads every .yft model, extracts the real UV shells, and renders each one as a wire-frame overlay on a template PNG — one per vehicle, at up to 4096 × 4096.

04

Auto-patch your meta files

blueprintV automatically patches carcols.meta and carvariations.meta with the correct livery slot entries and backs up the originals. Drop your painted textures in and you're done.
